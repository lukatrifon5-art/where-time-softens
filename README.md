# Where Time Softens

A one-page landing for an unhurried anti-aging clinic — a demo concept.
Static HTML/CSS/JS, no build step.

**Concept:** the light of a single slow day. As you scroll, the page warms from
palest dawn to golden dusk — time, passing gently. Treatments are measured in
the time they take; the experience is kept as a strip of film.

- `index.html` — the page
- `assets/styles.css` — styles (champagne palette, Cormorant Garamond + Mulish)
- `assets/main.js` — load settle, scroll reveals, daylight wash
- `assets/img/` — imagery (free-license, Pexels)
- `docs/DESIGN-SPEC.md` — the design brief

Booking links out to splendessa.com. Contact details are fictional.
